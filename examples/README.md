# Complete documentation examples

These files are copied from the exact executed documentation sources. They use
trusted KDP_* environment configuration and synthetic/actual Sandbox only.
Follow the public language guide for the complete clean application layout:
https://licensing.kdpika.com/docs/v1/sdks/csharp

Session examples run beside an installed SDK source directory in a consuming
application; C# project references and PHP KDP_SDK_DIR must point to that exact
directory. Do not assume every example path is relative to this examples folder.
Member examples use isolated local state and explicit synthetic models; they are
not a replacement for real signature/status/time/binding checks. No real key,
token, private signing key or customer data is distributed in these examples.
